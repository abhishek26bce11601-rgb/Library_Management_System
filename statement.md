# Project Statement

## Problem Statement

Manual library records make it difficult to track available books, member details, issued books, return dates and overdue fines. The project provides a small digital system that stores these records and automates the main library workflow.

## Scope

The system covers:

- Book CRUD operations
- Member CRUD operations
- Book issue and return
- Copy availability tracking
- Overdue calculation
- Fine calculation
- Dashboard and reports

The project is designed for a small academic or department library.

## Target Users

- Librarian
- Library staff
- Students who use the library through the librarian-operated system

## High-Level Features

- Persistent SQLite database
- Input validation
- Search functionality
- Issue/return workflow
- Fine calculation
- Overdue report
- Unit tests
